Startup Configuration 흐름 SPFILE / PFILE

STARTUP 시 Oracle은 SPFILE 또는 PFILE을 읽어 초기화 파라미터를 확인합니다. 이후 파라미터 값에 따라 SGA를 할당하고 백그라운드 프로세스를 시작하며, CONTROL_FILES 파라미터에 지정된 control file을 읽어 데이터베이스를 mount합니다.

ARCHIVELOG / Recovery 흐름 LGWR → ARCn → Recovery

LGWR는 변경 내용을 online redo log에 기록합니다. Log switch가 발생하면 ARCHIVELOG 모드에서는 ARCn이 이전 redo log group을 archived redo log로 복사합니다. Archived redo log는 백업 이후 변경분을 재적용하는 media recovery와 특정 시점 복구에 사용됩니다.

1. Tablespace (테이블스페이스) Logical

데이터베이스 저장 공간을 논리적으로 구분하는 단위입니다. 하나의 테이블스페이스는 하나 이상의 물리적인 Data File로 구성됩니다.

2. Segment (세그먼트) Logical

테이블, 인덱스, Undo, Temporary 객체처럼 특정 데이터베이스 객체가 사용하는 논리적 저장 영역입니다.

참고. Temporary Tablespace / Temp File Temporary

TEMP tablespace는 영구 객체 저장용 data file이 아니라 temp file을 사용합니다. 정렬, 해시, 임시 결과 집합처럼 작업 중에만 필요한 데이터를 저장하며, temp file 정보는 DBA_TEMP_FILES와 V$TEMPFILE에서 확인합니다.

3. Extent (익스텐트) Logical

익스텐트는 논리적으로 연속된 Oracle data block의 집합입니다. 세그먼트에 더 많은 공간이 필요하면 Oracle Database는 해당 세그먼트에 하나 이상의 익스텐트를 추가로 할당합니다.

4. Block (블록) Min I/O Unit

Oracle data block은 Oracle Database가 데이터를 저장하고 읽는 최소 논리 I/O 단위입니다. 크기는 DB_BLOCK_SIZE 파라미터로 결정되며, 많은 환경에서 8KB를 사용하지만 고정값은 아닙니다.
