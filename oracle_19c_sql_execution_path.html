Logical Read

Server Process가 Buffer Cache에 있는 Oracle Block을 접근하는 동작입니다. Cache Hit뿐 아니라 Physical Read로 적재된 블록을 이후 처리하는 과정도 Logical Read에 포함됩니다.

Physical Read

필요한 블록이 Buffer Cache에 없을 때 Data File에서 블록을 읽는 I/O입니다. 일반적인 Buffered Read에서는 읽은 블록을 Buffer Cache에 적재한 뒤 처리합니다.
