# 오라클 데이터베이스 아키텍처 개요

오라클 데이터베이스는 단순한 데이터 저장 공간을 넘어, 다수의 컴포넌트가 정교하게 협력하는 복잡한 시스템이다. 성능 최적화 및 장애 진단을 위해서는 데이터베이스 아키텍처의 각 구성 요소가 수행하는 역할과 상호 작용 원리를 명확히 이해해야 한다.

---

## 1. 데이터베이스 메모리 및 스토리지 구조

### 1) SGA (System Global Area)
* **정의**: 데이터베이스 인스턴스의 핵심이 되는 공유 메모리 영역이다.
* **주요 구성 요소**:
  * **Buffer Cache**: 디스크에서 읽어들인 데이터 블록을 메모리에 캐싱하여 I/O 성능을 높인다.
  * **Redo Log Buffer**: 데이터베이스에 발생한 모든 변경 내역을 임시로 저장하여 복구(Recovery)에 대비한다.
  * **Shared Pool**: 파싱된 SQL 문, 실행 계획, 데이터 딕셔너리 정보 등을 캐싱하여 재사용성을 극대화한다.
  * 데이터베이스에 접속한 모든 사용자 세션이 SGA 영역을 공유하여 사용한다.

### 2) 백그라운드 프로세스
* **정의**: 오라클 데이터베이스 인스턴스가 원활하게 동작하도록 메모리(SGA)와 물리적 디스크 간의 작업을 백그라운드에서 비동기적으로 처리하는 운영체제 프로세스들이다.
* **주요 프로세스**:
  * **DBWn (Database Writer)**: Buffer Cache에서 변경된 데이터(Dirty Buffer)를 디스크의 데이터 파일에 기록한다.
  * **LGWR (Log Writer)**: Redo Log Buffer에 기록된 트랜잭션 변경 내역을 디스크의 Redo Log File에 기록한다.
  * **CKPT (Checkpoint)**: 체크포인트 이벤트를 발생시키고, 동기화 정보를 데이터 파일 헤더와 컨트롤 파일에 기록한다.
  * **SMON (System Monitor)**: 인스턴스 복구, 임시 공간 정리 등 시스템 수준의 유지보수 작업을 수행한다.
  * **PMON (Process Monitor)**: 비정상 종료된 사용자 프로세스의 리소스를 회수하고 롤백을 수행한다.

### 3) 물리적 스토리지 (Disk)
* **정의**: 데이터가 영구적으로 보존되는 물리적 파일 저장소다.
* **주요 구성 파일**:
  * **Data Files**: 실제 테이블, 인덱스 등 사용자 데이터가 물리적으로 저장되는 파일이다.
  * **Redo Log Files**: 장애 발생 시 데이터 복구를 위해 트랜잭션 변경 내역이 순차적으로 기록되는 파일이다.
  * **Undo Files**: 롤백(Rollback) 및 읽기 일관성(Read Consistency) 보장을 위해 변경 전 원본 데이터가 저장되는 파일이다.
  * **Control Files**: 데이터베이스의 물리적 구조 정보, 현재 상태, 동기화 정보(SCN) 등을 담고 있는 핵심 설정 파일이다.

---

## 2. 데이터 처리 흐름의 이해

사용자가 SQL 문을 실행하여 데이터를 변경(DML)하는 과정은 메모리와 디스크, 그리고 백그라운드 프로세스의 협업으로 이루어진다.

1. 사용자가 데이터를 변경하면, 해당 데이터 블록이 **Buffer Cache**로 로드되고 메모리 상에서 값이 변경된다. (Dirty Buffer 발생)
2. 변경된 내용과 변경 전 원본 데이터에 대한 정보는 **Redo Log Buffer**에 즉각 기록된다.
3. 사용자가 `COMMIT`을 수행하면, **LGWR** 프로세스가 Redo Log Buffer의 내용을 디스크의 **Redo Log File**에 먼저 기록하여 데이터 유실을 방지한다. (Write-Ahead Logging 방식)
4. 이후 시스템 부하가 적을 때나 특정 조건(체크포인트 등)이 만족되면, **DBWn** 프로세스가 Buffer Cache의 변경된 블록들을 디스크의 **Data File**에 일괄적으로 내려쓴다.

이러한 아키텍처적 분리 설계는 디스크 I/O 병목을 최소화하면서도 트랜잭션의 ACID(원자성, 일관성, 고립성, 지속성) 특성을 완벽하게 보장하는 오라클 데이터베이스 성능의 근간이 된다.
