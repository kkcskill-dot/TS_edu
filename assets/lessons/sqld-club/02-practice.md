# 실전 문제: 데이터 모델과 SQL

> [!TIP]
> **출제 포인트**
> 1과목 2장 '데이터 모델과 SQL'에서는 **정규화**, **반정규화**, **대량 데이터 성능 최적화**, **분산 데이터베이스**가 집중적으로 출제됩니다. 특히 제1~3정규형의 차이와 반정규화 기법의 판단이 핵심입니다.

---

## 1. 정규화(Normalization)

### 📝 문제 1
**다음 중 제3정규형(3NF)에 대한 설명으로 올바른 것은?**
1. 모든 속성은 반드시 하나의 원자값(Atomic Value)만을 가져야 한다.
2. 엔터티의 일반속성은 주식별자 전체에 종속적이어야 한다.
3. 엔터티의 일반속성 간에는 서로 종속적이지 않아야 한다. (이행적 함수 종속 제거)
4. 다대다(M:N) 관계를 해소하기 위해 교차 엔터티를 생성해야 한다.

> [!NOTE]
> **정답 및 해설: 3번**
> - 1정규화(1NF): 원자성 확보 (다중값 속성 분리)
> - 2정규화(2NF): 부분 함수 종속성 제거 (주식별자 일부에 종속되는 속성 분리)
> - **3정규화(3NF): 이행적 함수 종속성 제거 (일반 속성끼리의 종속성 분리)**

---

## 2. 반정규화(De-normalization)

### 📝 문제 2
**다음 중 조회 성능을 향상시키기 위해 적용하는 반정규화 기법 중 성격이 다른 하나는?**
1. 테이블 병합 (1:1 관계, 1:M 관계 병합)
2. 통계 테이블 추가 (Summary Table)
3. 테이블 수직 분할 (Vertical Partitioning)
4. 중복 속성 추가 (Derived Attribute)

> [!NOTE]
> **정답 및 해설: 3번**
> 테이블 수직/수평 분할은 정규화를 완료한 후 디스크 I/O 성능 향상이나 데이터 경합을 줄이기 위해 물리적인 구조를 나누는 기법입니다. (반정규화는 주로 데이터를 '중복'시키는 방향으로 진행됩니다.)

---

## 3. 대량 데이터에 따른 성능 (파티셔닝)

### 📝 문제 3
**하나의 테이블에 대량의 데이터가 적재되어 인덱스 트리가 너무 커지거나, 데이터 조회가 느려지는 현상을 해결하기 위해 데이터를 물리적으로 분할하는 기법은?**
1. 파티셔닝 (Partitioning)
2. 클러스터링 (Clustering)
3. 뷰 (View)
4. 동의어 (Synonym)

> [!NOTE]
> **정답 및 해설: 1번**
> 대량의 데이터를 물리적으로 나누어 저장하는 기법을 **파티셔닝(Partitioning)**이라고 합니다. 논리적으로는 하나의 테이블이지만 물리적으로는 여러 개의 데이터 파일에 나뉘어 저장되어 I/O 경합을 줄이고 관리 용이성을 높입니다. RANGE, LIST, HASH 파티셔닝 등이 있습니다.

---

## 4. 분산 데이터베이스

### 📝 문제 4
**분산 데이터베이스 아키텍처 중, 본사의 데이터를 지사에 물리적으로 복제하여 네트워크 트래픽을 줄이고 로컬 조인(Local Join)을 가능하게 하여 조회 성능을 극대화하는 기법은?**
1. 분할(Fragmentation) 분산
2. 복제(Replication) 분산
3. 할당(Allocation) 분산
4. 집계(Aggregation) 분산

> [!NOTE]
> **정답 및 해설: 2번**
> 마스터 데이터베이스의 데이터를 다른 노드에 물리적으로 동일하게 복사해 두는 기법을 **테이블 복제(Replication) 분산**이라고 합니다. 이는 네트워크 비용을 줄이고 데이터 읽기 성능을 획기적으로 개선합니다.
