# 2과목. SQL 기본 및 활용
## 1장. SQL 기본

> [!TIP]
> **개발자를 위한 가이드**
> ORM(Hibernate, Prisma 등)이 SQL을 대신 짜주는 시대라지만, 복잡한 비즈니스 통계나 튜닝을 위해서는 직접 네이티브 SQL을 다룰 줄 알아야 합니다. 이 단원은 SQL의 기본 뼈대를 잡는 가장 중요한 영역입니다.

---

### 1. 관계형 데이터베이스와 SQL 개요
*   **관계형 DB (RDB)**: 데이터를 2차원 표(Table = 컬럼 + 행) 형태로 저장하며, 집합 연산과 관계 연산이 가능합니다. 이상 현상과 중복을 제거(정규화)하여 데이터 무결성을 보장합니다.
*   **SQL (Structured Query Language)**: RDB에서 데이터를 정의, 조작, 제어하기 위해 사용하는 언어입니다.

---

### 2. SELECT 문과 실행 순서 🏆 (매우 중요)

#### SELECT 문장의 논리적 실행 순서
```sql
SELECT 컬럼명 [ALIAS명]        -- 5. 데이터를 출력/계산한다.
  FROM 테이블명                 -- 1. 발췌 대상 테이블을 참조한다.
 WHERE 조건식                   -- 2. 대상 데이터가 아닌 것은 제거한다.
 GROUP BY 그룹컬럼              -- 3. 행들을 소그룹화한다.
HAVING 그룹조건식               -- 4. 그룹핑된 값 중 조건에 맞는 것만 남긴다.
 ORDER BY 정렬컬럼;             -- 6. 데이터를 정렬한다.
```
> 💡 **주의점**: `ORDER BY` 절에는 `SELECT` 절에 명시되지 않은 컬럼도 사용할 수 있습니다. 단, `GROUP BY`를 사용한 경우 `ORDER BY`에는 `GROUP BY` 컬럼이나 집계 함수만 올 수 있습니다.

#### TOP N 쿼리 (출력 행 수 제한)
*   **Oracle**: `ROWNUM` 이라는 가상 컬럼(Pseudo Column)을 사용합니다. (`WHERE ROWNUM <= 3`)
    *   *주의*: Oracle에서 정렬(ORDER BY)과 ROWNUM을 함께 쓰면 정렬되기 전의 임의의 N건을 가져온 뒤 정렬하게 되므로 인라인 뷰를 사용해야 합니다.
*   **SQL Server**: `TOP(N)` 구문을 `SELECT` 바로 뒤에 사용합니다. (`SELECT TOP(3) ...`)

### 3. 내장 함수 (Function)

#### 단일행 함수 (Single Row Function)
각 행마다 개별적으로 1:1 작업을 수행하여 결과를 반환합니다.

*   **문자형 함수**: `LOWER`, `UPPER`, `SUBSTR`, `LENGTH`, `LTRIM`, `RTRIM`, `CONCAT`(또는 `||` / `+`)
*   **숫자형 함수**: `ABS`(절대값), `SIGN`(양/음수 판별), `MOD`(나머지), `CEIL`(올림), `FLOOR`(버림), `ROUND`(반올림), `TRUNC`(버림)
*   **날짜형 함수**: `SYSDATE` (Oracle의 현재 날짜/시간), `EXTRACT`(년/월/일 추출)
*   **변환형 함수**: 
    *   *명시적 변환*: `TO_NUMBER`, `TO_CHAR`, `TO_DATE` (Oracle) / `CAST`, `CONVERT` (SQL Server)
    *   *암시적 변환*: 데이터베이스가 자동으로 형변환 수행 (권장하지 않음)
*   **분기 처리 (IF-THEN-ELSE)**:
    *   `CASE WHEN 조건 THEN 참일때값 ELSE 거짓일때값 END` (표준 방식)
    *   `DECODE(컬럼, 기준값1, 결과1, 디폴트값)` (Oracle 전용)

### 4. WHERE 절과 NULL 관련 연산 🏆 (함정 단골)

원하는 데이터만 필터링하기 위해 `WHERE` 절을 사용합니다. 부정 연산자 -> 비교 연산자 -> 논리 연산자(AND, OR) 순으로 처리됩니다.

#### 비교 연산자
*   `=` (같다), `<>` 또는 `!=` (같지 않다), `>`, `<`, `>=`, `<=`
*   `BETWEEN a AND b` (a와 b 사이, 양끝 값 포함)
*   `IN (list)` (리스트 내의 값 중 하나라도 일치하면 참)
*   `LIKE '비교문자열'` (`%`는 0개 이상 문자, `_`는 1개 문자)

#### NULL 관련 데이터 처리 ⚠️
*   `NULL`은 아직 정의되지 않은, 알 수 없는 값입니다. 0이나 공백(' ')과는 다릅니다.
*   `NULL`과 어떠한 사칙연산(+,-,*,/)을 수행해도 결과는 무조건 `NULL`입니다.
*   `NULL = NULL` 비교의 결과는 FALSE(정확히는 UNKNOWN)입니다. 반드시 `IS NULL` 또는 `IS NOT NULL`로 검사해야 합니다.

#### NULL 관련 함수
1.  `NVL(표현식1, 표현식2)` / `ISNULL()`: 표현식1이 NULL이면 표현식2를 반환합니다.
2.  `NULLIF(표현식1, 표현식2)`: 두 값이 같으면 NULL, 다르면 표현식1 반환.
3.  `COALESCE(표현식1, 표현식2, ...)`: 나열된 인자 중 NULL이 아닌 첫 번째 값을 반환합니다.

### 5. GROUP BY 와 HAVING 절

여러 행을 소그룹으로 묶어 통계 결과를 얻을 때 사용합니다.

#### 집계 함수 (다중행 함수)
`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`
> 💡 **핵심 포인트**: `COUNT(*)`는 NULL 값을 포함한 전체 행 수를 계산하지만, `COUNT(컬럼명)`, `SUM(컬럼명)`, `AVG(컬럼명)` 등은 **해당 컬럼의 값이 NULL인 행을 완전히 제외**하고 계산합니다.

#### HAVING 절
`GROUP BY`로 묶인 소그룹에 대한 필터링 조건을 지정합니다. (`WHERE` 절에서는 집계 함수를 사용할 수 없으므로 `HAVING`을 사용해야 합니다.)

### 6. 조인 (JOIN) 기초

두 개 이상의 테이블을 연결하여 데이터를 추출하는 릴레이셔널 DB의 꽃입니다. (일반적으로 PK-FK 연관관계에 의해 성립)

*   **EQUI JOIN (등가 조인)**: 두 테이블의 컬럼 값이 정확하게 일치(`=`)하는 경우.
*   **Non EQUI JOIN (비등가 조인)**: `=` 연산자가 아닌 `BETWEEN`, `>`, `<=` 등을 사용하여 조인하는 경우.
*   *(주의)*: 조인할 때 두 테이블에 동일한 이름의 컬럼이 있다면, 반드시 컬럼명 앞에 `테이블명.` 또는 `ALIAS명.` 접두사를 붙여 명확히 해야 합니다.
