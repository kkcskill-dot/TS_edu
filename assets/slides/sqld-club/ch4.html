표준 조인
OUTER JOIN — 결과 예측
-- 사원 없는 부서까지 모두 SELECT d.dname, e.ename FROM dept d LEFT JOIN emp e ON d.deptno = e.deptno;
OPERATIONS(40번)는 사원이 없어도 출력, ename은 NULL. Oracle 전통 표기 (+)는 없는 쪽에 붙임.
-- Oracle 전통식 = LEFT OUTER WHERE d.deptno = e.deptno(+);
함정
  • OUTER 조인 시 COUNT(e.empno)로 세야 NULL 제외
  • (+)는 OR·IN과 함께 못 씀(제약)
  • WHERE에 외부조인 테이블 조건 걸면 INNER처럼 됨
집합 연산자
UNION · INTERSECT · MINUS
연산자의미중복·정렬
UNION합집합중복 제거 + 정렬
UNION ALL합집합중복 허용 + 정렬 안 함
INTERSECT교집합중복 제거
MINUS(EXCEPT)차집합중복 제거
규칙·함정
  • 각 SELECT 컬럼 수·데이터 타입 일치
  • 컬럼명은 첫 번째 SELECT 기준
  • ORDER BY는 맨 마지막에 한 번만
  • 성능은 UNION ALL이 유리(정렬 X)

서브쿼리의 위치별 분류
종류위치특징
스칼라 서브쿼리SELECT 절행마다 1행 1열 반환
인라인 뷰FROM 절가상 테이블처럼

연산자
  • 단일행: = > < (1건 반환 전제)
  • 다중행: IN · ANY · ALL · EXISTS
  • 다중행에 = 쓰면 에러
서브쿼리
다중행 연산자 & 상관 서브쿼리
연산자의미
IN목록 중 하나라도 일치
> ANY최솟값보다 크면 참
> ALL최댓값보다 크면 참
EXISTS한 건이라도 있으면 참
-- 상관 서브쿼리: 바깥 행 참조 SELECT ename FROM emp e WHERE sal > (SELECT AVG(sal) FROM emp WHERE deptno=e.deptno);
함정
  • >ANY = 최소보다 큼, >ALL = 최대보다 큼
  • EXISTS는 존재 여부만(값 무관)
  • NOT IN + NULL → 결과 사라짐 (NOT EXISTS 권장)
계층형 질의
CONNECT BY (Oracle)
SELECT LEVEL, ename, mgr FROM emp START WITH mgr IS NULL -- 루트 CONNECT BY PRIOR empno = mgr; -- 부모→자식
요소의미
START WITH최상위(루트) 조건
CONNECT BY전개 규칙
PRIOR이전(부모) 행
LEVEL깊이(1부터)
방향
  • PRIOR 자식=부모 → 순방향(위→아래)
  • PRIOR 부모=자식 → 역방향
  • CONNECT_BY_ROOT, SYS_CONNECT_BY_PATH 보조
  • 실습(SQLite)은 미지원 — 개념만
그룹 함수
ROLLUP · CUBE · GROUPING SETS
함수생성하는 소계
ROLLUP(a,b)(a,b) → (a) → 전체 : 계층적 소계
CUBE(a,b)모든 조합 (a,b)(a)(b)(전체)
GROUPING SETS지정한 집합만
GROUPING(col)=1 이면 그 컬럼이 소계 행(집계로 묶임)임을 의미.
암기
  • ROLLUP 결과 수 = 인자 N+1 레벨
  • CUBE = 모든 부분집합 2ⁿ
  • 실습(SQLite) 미지원 — 개념·결과만
윈도우 함수
순위 함수 — RANK / DENSE_RANK / ROW_NUMBER
SELECT ename, sal, RANK() OVER (ORDER BY sal DESC) r, DENSE_RANK() OVER (ORDER BY sal DESC) dr, ROW_NUMBER() OVER (ORDER BY sal DESC) rn FROM emp;
값(공동 2위 2명)다음 순위
RANK1,2,2,4 (건너뜀)
DENSE_RANK1,2,2,3 (안 건너뜀)
ROW_NUMBER1,2,3,4 (무조건 유일)
필수 구분
  • RANK는 동순위 뒤 건너뜀
  • DENSE_RANK는 안 건너뜀
  • ROW_NUMBER는 동률 없이 1씩
윈도우 함수
집계·순서 윈도우 — PARTITION / LAG / LEAD
-- 부서별 급여합(행은 유지) SUM(sal) OVER (PARTITION BY deptno) -- 누적합 SUM(sal) OVER (ORDER BY sal ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) -- 이전/다음 행 값 LAG(sal) OVER (ORDER BY sal), LEAD(sal) OVER (ORDER BY sal)
개념
  • PARTITION BY = 그룹(행 수 유지 ↔ GROUP BY는 축약)
  • LAG/LEAD 기본 1행, 없으면 NULL
  • FIRST_VALUE·LAST_VALUE·NTILE 보조
