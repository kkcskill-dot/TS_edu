관리 구문

DDL · 제약조건 · DML · MERGE · TCL(트랜잭션) · DCL · VIEW
— 데이터를 정의·조작·제어하는 구문과 그 동작 규칙.

DDL
DDL — CREATE / ALTER / DROP / TRUNCATE
CREATE TABLE emp (empno NUMBER PRIMARY KEY, ename VARCHAR2(20)); ALTER TABLE emp ADD (sal NUMBER); ALTER TABLE emp MODIFY (ename VARCHAR2(30)); DROP TABLE emp;

시험 1순위
  • DDL은 Auto Commit
  • TRUNCATE는 빠르고 되돌릴 수 없음
  • DELETE는 WHERE로 일부 삭제 가능
제약조건
제약조건 (Constraints)
제약의미
PRIMARY KEY유일 + NOT NULL (테이블당 1개)
UNIQUE유일(단, NULL은 허용)
NOT NULLNULL 금지
FOREIGN KEY부모 PK/UK 참조(참조 무결성)
CHECK값 조건 (예: sal>0)
DEFAULT미입력 시 기본값
함정
  • PK = UNIQUE + NOT NULL
  • UNIQUE는 NULL 여러 개 허용
  • FK는 부모에 없는 값 입력 불가
  • DEFAULT는 NULL 명시 입력 시 적용 안 됨
DML
INSERT / UPDATE / DELETE
INSERT INTO dept (deptno, dname) VALUES (50, 'IT'); UPDATE emp SET sal = sal * 1.1 WHERE deptno = 30; DELETE FROM emp WHERE empno = 7369;
WHERE 빠진 UPDATE/DELETE는 전체 행에 적용 — 시험·실무 단골 사고.
포인트
  • INSERT 컬럼 생략 시 전체 컬럼 순서로 입력
  • DML은 커밋 전까지 미확정
  • NOT NULL 컬럼 누락 → 에러
DML
MERGE — 있으면 UPDATE, 없으면 INSERT
MERGE INTO target t USING source s ON (t.id = s.id) WHEN MATCHED THEN UPDATE SET t.val = s.val WHEN NOT MATCHED THEN INSERT (id, val) VALUES (s.id, s.val);
개념
  • 한 문장으로 UPSERT 처리
  • ON 조건 일치 → UPDATE / 불일치 → INSERT
  • 대량 동기화·적재에 사용
TCL
트랜잭션 — COMMIT / ROLLBACK / SAVEPOINT
UPDATE emp SET sal = 0 WHERE empno = 7369; SAVEPOINT a; DELETE FROM emp WHERE deptno = 10; ROLLBACK TO a; -- DELETE만 취소, UPDATE는 유지 COMMIT; -- UPDATE 확정
트랜잭션 특성 ACID: 원자성·일관성·고립성·지속성.
함정
  • COMMIT 후에는 ROLLBACK 불가
  • DDL 실행 시 앞선 DML도 자동 커밋
  • ROLLBACK TO 세이브포인트 = 부분 취소
DCL
DCL — GRANT / REVOKE
GRANT SELECT, INSERT ON emp TO scott; REVOKE INSERT ON emp FROM scott; GRANT SELECT ON emp TO scott WITH GRANT OPTION;
ROLE: 권한의 묶음. 사용자에게 ROLE을 부여하면 묶음 권한을 한 번에 부여.
개념
  • 시스템 권한(CREATE…) vs 객체 권한(SELECT…)
  • WITH GRANT OPTION: 받은 권한 재부여 가능
  • REVOKE로 회수(연쇄 회수 주의)
VIEW
뷰 (View)
CREATE VIEW emp30 AS SELECT empno, ename, sal FROM emp WHERE deptno = 30;

장점

독립성·편의성·보안(컬럼/행 제한).

특징

실제 데이터 없음(가상). 원본 변경 시 반영.

포인트
  • 뷰는 물리 데이터 저장 안 함
  • 단순 뷰는 INSERT/UPDATE 가능(제약 있음)
  • 독립성: 원본 테이블 구조 변화 흡수
한 장 정리
5강좌 핵심 & 빈출
  • DELETE(DML·롤백O) vs TRUNCATE(DDL·롤백X) vs DROP
  • PK=UNIQUE+NOT NULL · UNIQUE는 NULL 허용
  • MERGE = UPSERT
  • COMMIT 후 롤백 불가 · DDL은 Auto Commit
  • GRANT/REVOKE·ROLE · VIEW는 가상(보안)
