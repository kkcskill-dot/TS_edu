SELECT
SELECT 실행(논리) 순서 🏆
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
작성 순서SELECT … FROM … WHERE … GROUP BY … HAVING … ORDER BY
실행 순서FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
왜 중요한가
  • SELECT 별칭은 WHERE/GROUP BY/HAVING에서 사용 불가(아직 미생성)
  • ORDER BY에서는 별칭 사용 가능(SELECT 이후 실행)
  • WHERE는 그룹 전, HAVING은 그룹 후 필터
함수
단일행 함수 — 문자·숫자·날짜
구분예
문자SUBSTR, INSTR, LENGTH, LTRIM/RTRIM, REPLACE, CONCAT(||)
숫자ROUND, TRUNC, MOD, CEIL, FLOOR

단일행 함수는 행마다 1개 결과. 중첩 가능. SELECT·WHERE·ORDER BY 등 어디서나 사용.
함정
  • SUBSTR 인덱스 1부터 시작
  • ROUND(123.45,1)=123.5 / TRUNC는 버림
  • 문자+숫자 연산 시 묵시적 형변환 주의
함수
NULL 관련 함수
함수의미
NVL(A,B)A가 NULL이면 B
NVL2(A,B,C)A가 NULL 아니면 B, NULL이면 C
NULLIF(A,B)A=B면 NULL, 아니면 A
COALESCE(...)첫 번째 NULL이 아닌 값
-- 커미션 없으면 0으로 SELECT ename, sal + NVL(comm, 0) AS 총액 FROM emp;
자주 틀림
  • NVL2 인자 순서(NotNull→B, NULL→C)
  • NULLIF는 같으면 NULL
  • SQLite 실습 시 NVL→IFNULL 로 동작
함수
CASE 식 & DECODE
-- CASE (표준, 범위 비교 가능) SELECT ename, CASE WHEN sal>=3000 THEN 'A' WHEN sal>=2000 THEN 'B' ELSE 'C' END AS 등급 FROM emp; -- DECODE (Oracle, 등가비교만) SELECT DECODE(deptno,10,'총무',20,'연구','기타') FROM emp;
비교
  • CASE: 범위/조건 가능, ANSI 표준
  • DECODE: = 비교만, Oracle 전용
  • ELSE/기본값 없으면 NULL 반환
  • 위에서부터 먼저 참인 것 채택
NULL
3치 논리 (3VL) — TRUE·FALSE·UNKNOWN

NULL 때문에 SQL의 진리값은 2개가 아니라 3개입니다. NULL과 비교하면 참도 거짓도 아닌 UNKNOWN.

식결과
1 = 1TRUE
NULL = 1UNKNOWN
NULL = NULLUNKNOWN (같다고 안 봄)
WHERE는 TRUE인 행만 통과 → WHERE comm = NULL은 전부 UNKNOWN이라 0건. 반드시 IS NULL.
AND / OR 진리표
  • TRUE AND UNKNOWN → UNKNOWN
  • FALSE AND UNKNOWN → FALSE
  • TRUE OR UNKNOWN → TRUE
  • FALSE OR UNKNOWN → UNKNOWN
함정
  • NOT IN(목록에 NULL) → 전부 탈락 → NOT EXISTS 권장
WHERE
WHERE 연산자와 우선순위
종류연산자
비교= , > , < , >= , <= , <>
SQLBETWEEN a AND b · IN · LIKE · IS NULL
논리AND · OR · NOT
우선순위: NOT → AND → OR (괄호로 명시 권장)
함정
  • BETWEEN은 양 끝 포함
  • LIKE 와일드카드: % (0+), _ (1자)
  • IN (a,b,NULL) + NOT IN 에 NULL → 결과 없음 주의
  • AND가 OR보다 먼저 — 괄호 없으면 의도와 달라짐
집계
GROUP BY · HAVING · 집계 함수
SELECT deptno, AVG(sal) FROM emp GROUP BY deptno HAVING AVG(sal) >= 2000;
함수NULL 처리
COUNT(*)행 수(NULL 포함)
COUNT(col)NULL 제외 개수
SUM/AVG/MAX/MINNULL 제외
규칙·함정
  • SELECT의 비집계 컬럼은 전부 GROUP BY에 있어야 함
  • WHERE에는 집계함수 못 씀 → HAVING으로
  • WHERE로 먼저 행을 줄이면 성능↑
정렬
ORDER BY

기본 ASC(오름차순). 컬럼명·별칭·SELECT 순번으로 정렬 가능.

SELECT ename, sal FROM emp ORDER BY sal DESC, ename ASC; -- 2 DESC 도 가능
Oracle: NULL은 정렬 시 가장 큰 값으로 취급(ASC면 뒤, DESC면 앞). NULLS FIRST/LAST로 제어.
포인트
  • 실행 순서상 맨 마지막 → 별칭 사용 OK
  • 숫자 1,2…는 SELECT 컬럼 위치
  • DBMS마다 NULL 정렬 기본값 다름
조인
조인 기본 — 등가/비등가
-- 등가 조인 (PK-FK) SELECT e.ename, d.dname FROM emp e JOIN dept d ON e.deptno = d.deptno; -- 비등가 조인 (범위) SELECT e.ename, s.grade FROM emp e JOIN salgrade s ON e.sal BETWEEN s.losal AND s.hisal;
개념
  • 등가 조인: =로 연결(가장 흔함)
  • 비등가 조인: BETWEEN 등 범위
  • 조인 조건 빠지면 카티션 곱(N×M)
  • N개 테이블 조인 → 조건 최소 N-1개
결과 예측
함정 모음 — "이 SQL의 결과는?"
  • WHERE comm = NULL → 결과 0건 (IS NULL 써야)
  • NOT IN (서브쿼리에 NULL 포함) → 전체 0건
  • COUNT(comm) ≠ COUNT(*) (NULL 제외)
  • sal + comm 에서 comm NULL → 그 행 NULL
  • '10'+1 같은 묵시적 형변환 → 11
시험 전략
  • NULL 보이면 먼저 의심
  • 집계는 NULL 제외라는 점 항상 체크
  • 실습 메뉴에서 직접 돌려 확인
