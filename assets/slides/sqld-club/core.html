1과목 · 모델링
반정규화 & 트레이드오프

조회 성능을 위해 의도적으로 중복을 허용. 단, 정합성 관리 비용이 생긴다.

대상

테이블·컬럼·관계 반정규화, 집계/이력 테이블.

비용

중복 → 갱신 시 정합성·저장공간 부담.

순서가 중요
  • 먼저 정규화로 올바른 구조
  • 측정된 병목에 한해 반정규화
  • 슈퍼/서브타입 변환(단일/분리/통합)
  • NULL·이력은 모델로 관리
2과목 · SQL 기본
SELECT 실행 순서
FROM→ WHERE→ GROUP BY→ HAVING→ SELECT→ ORDER BY
그래서: SELECT 별칭(alias)은 WHERE·GROUP BY에선 못 쓰고 ORDER BY에선 쓸 수 있다.
연산자 우선순위
  • NOT > AND > OR — 괄호로 명확히
  • 비교·BETWEEN·IN·LIKE·IS NULL
  • <>, !=, ^= 모두 not equal
  • ORDER BY 기본 ASC, NULL 정렬 위치 주의
2과목 · 단골 함정
NULL 처리
  • 집계함수(SUM·AVG·COUNT(컬럼))는 NULL 제외
  • COUNT(*)는 NULL 포함 전체 행
  • NULL과 사칙연산 = NULL
  • = NULL은 거짓 → IS NULL 사용
NULL 함수
  • NVL(a, b) — a가 NULL이면 b
  • NVL2(a, b, c) — a NULL아니면 b, NULL이면 c
  • COALESCE(...) — 첫 non-NULL
  • NULLIF(a, b) — 같으면 NULL

분류예

2과목 · 집계
GROUP BY / HAVING
SELECT deptno, COUNT(*), AVG(sal) FROM emp GROUP BY deptno HAVING COUNT(*) >= 2;
규칙 · 함정
  • SELECT의 비집계 컬럼은 모두 GROUP BY에
  • WHERE(그룹 전) vs HAVING(그룹 후)
  • 집계함수는 WHERE에 못 씀 → HAVING
  • 그룹 함수: ROLLUP·CUBE·GROUPING SETS
2과목 · 활용
조인 (JOIN)

INNER

양쪽 매칭 행만.

OUTER

LEFT/RIGHT/FULL — 한쪽 행 보존, 미매칭은 NULL.

CROSS

카티션 곱(M×N).

SELF

자기 테이블 조인(별칭).

표준 조인 문법
  • ON(임의 조건) vs USING(동일 컬럼)
  • NATURAL JOIN — 같은 이름 컬럼 자동
  • 오라클 전용 (+)는 OUTER 표기
  • OUTER 조인 시 NULL 행수 예측이 단골
2과목 · 활용
집합 연산자
연산자의미
UNION합집합 — 중복 제거 + 정렬
UNION ALL합집합 — 중복 유지·정렬 X
INTERSECT교집합
MINUS차집합(A−B)
핵심 포인트
  • UNION ALL 외엔 정렬(SORT) 동반 → 느림
  • 중복 없으면 UNION ALL이 최선
  • 각 SELECT의 컬럼 수·타입 일치
  • ORDER BY는 마지막에 한 번
2과목 · 활용
서브쿼리

스칼라

SELECT 절, 1행 1열 반환.

인라인 뷰

FROM 절의 서브쿼리.

중첩

WHERE 절. 단일/다중행.

상관

메인 행마다 반복 — 성능 주의.

다중행 연산자
  • IN, ANY/SOME, ALL
  • EXISTS — 존재 여부(상관)
  • > ALL = 최댓값보다, > ANY = 최솟값보다
  • 서브쿼리에 NULL 섞이면 NOT IN 주의
