# SQL 기초 (공통 베이스)

- **트랙**: 공통 (튜닝/설계 두 트랙의 선수)
- **레벨**: L1
- **상태**: **운영 중** ✅ (학습자료 6세션 + 인터랙티브 실습 6종 + 종합 퀴즈 구현)
  - 실습: 쿼리 결과 예측 · JOIN 시각화 · WHERE 필터 · GROUP BY 집계 · 정렬/Top-N · 집합 연산
- **대상**: SQL 입문자, 데이터 분석을 시작하는 실무자
- **선수과정**: 없음
- **목표**: 혼자서 정확한 SELECT를 작성하고, 결과를 예측하며, 기본 DML/트랜잭션을 다룬다.

## 세션 구성
| 세션 | 학습자료 | 실습 | 퀴즈 |
|---|---|---|---|
| 1. SQL 기본 | SELECT/WHERE/ORDER BY, 문자·숫자·날짜·NULL 함수 | SQL 작성 챌린지 | 결과 예측 |
| 2. 집계 & 그룹화 | GROUP BY/HAVING, 집계함수 | 집계 챌린지 | 그룹 함수 판별 |
| 3. 조인 & 집합 | INNER/OUTER/SELF, UNION/MINUS/INTERSECT | 조인 문법 실습 | 조인 결과 예측 |
| 4. 서브쿼리 & 분석함수 | 스칼라/인라인뷰/상관 서브쿼리, 윈도우 함수(RANK/SUM OVER) | 작성 챌린지 | 분석함수 적용 |
| 5. DML & 트랜잭션 | INSERT/UPDATE/DELETE/MERGE, COMMIT/ROLLBACK, 격리수준 맛보기 | DML 시뮬레이션 | 트랜잭션 시나리오 |
| 6. 실전 패턴 | 페이지네이션·Top-N·피벗, 실행계획 살짝 보기(→튜닝 트랙 연결) | 미니 챌린지 | 종합 |
