# 데이터 모델링

- **트랙**: B · DB 설계
- **레벨**: L2
- **상태**: 기획
- **대상**: 스키마를 설계하거나 리뷰하는 개발자/DBA
- **선수과정**: [SQL 기초](../foundation/sql-foundation.md)
- **목표**: 업무 요건을 정규화된 데이터 모델로 옮기고, 반정규화 트레이드오프를 판단한다.

## 세션 구성
| 세션 | 학습자료 | 실습 |
|---|---|---|
| 1. 개념/논리 모델링 | 엔터티·속성·관계, 식별/비식별, ERD | ERD 읽기·작성 |
| 2. 정규화 | 함수종속, 1NF~BCNF, 이상현상 | 정규화 변환기 |
| 3. 반정규화 | 의도적 중복, 조회↔갱신 비용, 집계 테이블 | 비용 비교 |
| 4. 키 설계 | 자연키 vs 대리키, 시퀀스/IDENTITY, 복합키 | 키 설계 진단 |
| 5. 이력/코드/계층 모델 | 이력관리, 코드 테이블, 계층/재귀 구조 | 패턴 실습 |
