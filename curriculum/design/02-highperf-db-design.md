# 고성능 DB 설계 (DBA 설계·운영)

- **트랙**: B · DB 운영(DBA)
- **레벨**: L3
- **상태**: **기획 완료** (구현 대기)
- **대상**: DB 운영자(DBA) / DB 담당 백엔드
- **선수과정**: [데이터 모델링](01-data-modeling.md)
- **목표**: 설계 결정(테이블/인덱스)부터 물리 운영(테이블스페이스/파티션/통계)까지 손으로 익힌다.

## 세션 구성
| 세션 | 학습자료(이론) | 실습 랩 | 비고 |
|---|---|---|---|
| 1. 데이터 모델링 & 정규화 | 1NF~BCNF, 함수종속, 반정규화 트레이드오프 | **정규화 변환기**: 비정규→1·2·3NF 단계 분해, 이상현상 데모, 반정규화 비용 비교 | 신규 |
| 2. 테이블 설계 & 타입 | 데이터 타입, NULL 설계, 제약, 키 전략, 행 길이/마이그레이션 | **설계 검토기**: 과대 타입·형변환 유발·FK 누락 진단·교정 | 플랜진단 패턴 재사용 |
| 3. 인덱스 설계 | 결합 인덱스 컬럼 순서, 선택도/클러스터링 팩터, 커버링/FBI/비트맵, DML 오버헤드 | **인덱스 설계 실험실**: 쿼리 집합에 최적 인덱스·순서 결정, 과다 인덱스 DML 패널티 | 인덱스 시뮬레이터 확장 |
| 4. 테이블스페이스 & 세그먼트 | TS/세그먼트/익스텐트/블록, ASSM, UNDO/TEMP, HWM, 행 이전, shrink/reorg | **공간 관리 대시보드**: 세그먼트 증가 추이·사용률, HWM·단편화 진단, 공간부족 대응 | 신규 |
| 5. 파티션 설계 & 라이프사이클 | Range/List/Hash/Composite/Interval, 키 선택, 로컬/글로벌 인덱스, 프루닝, **보존정책** | **파티션 라이프사이클 매니저**: Interval 자동 생성 → 만료 파티션 DROP/TRUNCATE → Exchange 적재 → 프루닝 확인 | 신규(핵심) |
| 6. 통계정보 관리 | 옵티마이저 통계, 히스토그램, METHOD_OPT/AUTO 잡, Stale 감지, 통계 잠금/Pending, 확장통계 | **통계 관리 콘솔**: Stale 감지, 수집 전후 플랜 변화, 히스토그램 효과, 확장통계 생성 | 성능진단·Adaptive 랩과 연결 |

*(선택) 세션 7. 운영 자동화 — 일상 점검 체크리스트, `DBMS_SCHEDULER` 잡, 모니터링 쿼리 모음.*

## 신규 핵심 랩(이 과정의 차별점)
