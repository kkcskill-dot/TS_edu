# DB 운영 전문가 (백업·복구·HA·모니터링)

- **트랙**: B · DB 운영(DBA)
- **레벨**: L4
- **상태**: 기획
- **대상**: 안정적 운영을 책임지는 운영 DBA
- **선수과정**: [고성능 DB 설계](02-highperf-db-design.md)
- **목표**: 백업·복구, 고가용성, 모니터링·장애대응으로 **무중단·안정 운영**을 수행한다.

## 세션 구성(초안)
| 세션 | 학습자료 | 실습 |
|---|---|---|
| 1. 백업 & 복구 | RMAN, 전체/증분 백업, 아카이브 로그, PITR, 복구 시나리오 | 복구 시나리오 진단 |
| 2. 고가용성 (HA/DR) | Data Guard·RAC 개념, Failover/Switchover, 이중화 | 장애 전환 시나리오 |
| 3. 모니터링 & 장애 대응 | Alert log·대기이벤트, AWR/ASH, 인시던트 대응 런북, 포스트모템 | ASH/AWR 분석 ♻️ |
| 4. 공간 & 자원 관리 | 테이블스페이스·UNDO·TEMP 운영, HWM·단편화, Resource Manager | 공간 관리 대시보드 🔗 |
| 5. 보안 & 감사 | 계정·권한·롤, 감사(Audit), 암호화·마스킹 기초 | 권한·감사 점검 |
| 6. 운영 자동화 | `DBMS_SCHEDULER` 잡, 일상 점검 체크리스트, 통계·유지보수 자동화 | 점검 스크립트 |

## 차별점
- 백업/복구·HA/DR·장애대응은 신규 시나리오형 랩. 모니터링은 소모임 **ASH/AWR**(♻️), 공간 관리는 고성능 DB 설계의 **공간 대시보드**(🔗) 연계.
