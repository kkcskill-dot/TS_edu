# Data Architect

- **트랙**: B · DB 설계
- **레벨**: L4
- **상태**: 기획
- **대상**: 시스템 전반의 데이터 구조를 설계·표준화하는 아키텍트
- **선수과정**: [고성능 DB 설계](02-highperf-db-design.md)
- **목표**: 단일 DB를 넘어 데이터 표준·통합·확장성·이행까지 아우르는 설계 역량을 갖춘다.

## 세션 구성(초안)
| 세션 | 학습자료 | 실습 |
|---|---|---|
| 1. 데이터 표준화 | 명명규칙, 도메인/용어 사전, 표준 데이터 타입 | 표준 점검 |
| 2. 대용량 설계 | 파티셔닝 전략, 샤딩 개념, 아카이빙/이력 분리 | 용량 산정 |
| 3. 통합 & 이행 | ETL/CDC 개념, 마이그레이션 전략, 무중단 이행 | 이행 시나리오 |
| 4. 가용성 & 확장성 | 이중화/복제 개념, 읽기 분산, 캐시 계층 | 아키텍처 설계 |
| 5. 거버넌스 | 품질·보안·수명주기 관리, 모델 형상관리 | 리뷰 체크리스트 |

## 참고 교재
- 데이터 아키텍처/모델링 표준 자료
