# TS Academy — 교육 로드맵 (마스터)

기술서비스팀 DB 교육 아카데미의 전체 로드맵입니다. 공통 베이스(SQL 기초) 위에 **두 개의 전문 트랙**이 올라갑니다.

> ⚠️ 이 아카데미는 **실무 역량 강화**가 목표입니다. 특정 자격증 취득을 목표로 하지 않으며, 단계 명칭도 역량 기준으로 표기합니다.
>
> 📌 **성능진단 소모임**(현재 운영 중인 사내 스터디)은 정규 교육과정과 **별개로** 운영됩니다 → [study-performance-club.md](study-performance-club.md). 정규 로드맵 과정들은 아래와 같이 순차 기획 중입니다.

```
        [ DB 튜닝 전문가 ]              [ DB 설계 전문가 ]      ← 트랙 목표 역량(정점)
               ▲                              ▲
     ┌─────────┴─────────┐          ┌─────────┴─────────┐
     │  DB 튜닝 마스터    │          │   Data Architect   │
     │ (성능진단·튜닝)    │          │                    │
     └─────────▲─────────┘          └─────────▲─────────┘
     ┌─────────┴─────────┐          ┌─────────┴─────────┐
     │   SQL 전문가       │          │  고성능 DB 설계    │
     └─────────▲─────────┘          └─────────▲─────────┘
     ┌─────────┴─────────┐          ┌─────────┴─────────┐
     │   SQL 튜닝 기본    │          │   데이터 모델링    │
     └─────────▲─────────┘          └─────────▲─────────┘
               └──────────────┬───────────────┘
                     ┌────────┴────────┐
                     │    SQL 기초      │           ← 공통 베이스
                     └─────────────────┘
```

## 트랙 A — DB 튜닝
SQL을 빠르게 만드는 역량. 실행계획 해석 → 성능 진단 → 튜닝 워크숍으로 심화.

| 레벨 | 과정 | 상태 | 커리큘럼 |
|---|---|---|---|
| L1 | SQL 기초 | **운영 중** | [foundation/sql-foundation.md](foundation/sql-foundation.md) |
| L2 | SQL 튜닝 기본 | 기획 | [tuning/01-sql-tuning-basics.md](tuning/01-sql-tuning-basics.md) |
| L3 | SQL 전문가 | 기획 | [tuning/02-sql-advanced.md](tuning/02-sql-advanced.md) |
| L4 | DB 튜닝 마스터 (성능진단·튜닝) | 기획 | [tuning/03-db-tuning-master.md](tuning/03-db-tuning-master.md) |
| ★ | DB 튜닝 전문가 (목표 역량) | — | — |

## 트랙 B — DB 설계
데이터를 잘 담는 역량. 모델링 → 물리 설계·운영 → 아키텍처로 심화.

| 레벨 | 과정 | 상태 | 커리큘럼 |
|---|---|---|---|
| L1 | SQL 기초 (공통) | **운영 중** | [foundation/sql-foundation.md](foundation/sql-foundation.md) |

| L3 | **고성능 DB 설계 (DBA 설계·운영)** | **기획 완료** | [design/02-highperf-db-design.md](design/02-highperf-db-design.md) |
| L4 | Data Architect | 기획 | [design/03-data-architect.md](design/03-data-architect.md) |
| ★ | DB 설계 전문가 (목표 역량) | — | — |

## 상태 범례
- **운영 중**: 학습자료·실습·퀴즈가 구현되어 서비스 중
- **기획 완료**: 세션/실습 구성안 확정, 구현 대기
- **기획**: 개요만 정의, 상세화 대기

## 참고 교재(레벨별)
- SQL 기초: 「친절한 SQL」 입문류, 데이터 분석 입문서
- SQL 튜닝 기본: 「친절한 SQL 튜닝」
- SQL 전문가: SQL 튜닝 심화 노트
- DB 튜닝 마스터: 「오라클 성능 고도화」
- 데이터 모델링: 「핵심 데이터 모델링」
