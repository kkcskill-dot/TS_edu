# 성능진단 소모임 4회차 1페이지 기획서 — 통합 장애진단 워크숍

> **확정안 v1.0 · 2026-07-23** | 후속 제작 기준 문서(SoT) | **교육 4시간 / 단일 회차**
>
> **기술 설계 연계:** 10개 지표의 기준선·과부하 수치, 인과 흐름, 증거 체인과 임계치 적용 원칙은 [`perf-club-session-4-integrated-diagnostic-scenario.md`](perf-club-session-4-integrated-diagnostic-scenario.md)를 따른다.

## 1. 과정 정의

| 항목 | 확정 내용 |
|---|---|
| **주제** | **“느린 DB, 60분 안에 증거로 결론내기”** — 실시간 징후 → AWR/ASH 이력 → 실행계획을 연결하는 통합 장애진단 워크숍 |
| **대상** | Oracle 운영·기술지원 경력 **1~5년 DBA/엔지니어**, 장애 시 SQL_ID는 찾지만 원인·조치 근거를 일관된 보고서로 정리하지 못하는 실무자 |
| **선수지식** | 1~3회차 이수 또는 진단퀴즈 70점 이상: ① V$SESSION·AAS·주요 Wait Event 해석 ② AWR/ASH에서 문제 구간·SQL_ID 추출 ③ DBMS_XPLAN의 Starts/E-Rows/A-Rows/Buffers 해석 |
| **교육시간** | **총 240분**(이론 35분, 시연 35분, 팀 실습 125분, 발표·피드백 35분, 평가 10분) / 휴식은 실습 전환 시간에 별도 운영 |
| **운영형태** | 2~3인 1조, Oracle 19c 기준 사전 생성 스냅샷·플랜 덤프를 사용하는 증거 기반 시나리오 실습 |
| **완료기준** | 개인 퀴즈 **70점 이상** + 팀 장애진단 보고서 루브릭 **80점 이상**. 미달자는 오진 구간 1회 재제출 |

## 2. 핵심 학습목표(수행 기준)

교육 종료 시 학습자는 다음을 수행한다.

1. 장애 타임라인에서 **문제 구간과 정상 기준선**을 구분하고, AAS/CPU/Top Wait로 병목 유형을 10분 내 분류한다.
2. AWR → ASH → SQL_ID → 실행계획으로 이어지는 **증거 체인**을 만들고, 최소 3개의 수치 근거로 원인을 설명한다.
3. 실행계획의 `Starts`, `E-Rows`, `A-Rows`, `Buffers`를 이용해 **최초 오차·최대 비용 노드**를 지목한다.
4. 즉시조치와 근본조치를 분리하고, **효과·위험·롤백 조건**을 포함한 실행 우선순위를 제안한다.
5. 1페이지 장애진단 보고서를 작성해 비DBA 이해관계자에게 **5분 이내**로 결론을 브리핑한다.

**범위 통제:** 1~3회차의 아키텍처, Wait Event 정의, AWR/ASH 구조, 플랜 오퍼레이션 설명은 재강의하지 않는다. 신규 파티셔닝·RAC·Exadata·SQL 문장 재작성 실습은 제외하고, 기존 지식의 연결·판단·보고에 집중한다.

## 4. 산출물 및 인수 기준

### 학습자 산출물
1. **장애 타임라인 1부** — 기준선/장애구간/회복구간 표시
2. **증거 체인 워크시트 1부** — AWR·ASH·XPLAN 근거 3개 이상, 원본 위치 명시
3. **1페이지 장애진단 보고서 1부** — 현상, 영향, 원인, 즉시/근본조치, 위험·롤백 조건
4. **5분 브리핑 자료 1장** 및 개인 Exit Ticket

### 제작 패키지(후속 제작자 납품물)
1. 강사용 슬라이드 **25장 이내**와 강의 스크립트
2. 학습자 워크북·1페이지 보고서 템플릿·정답 해설
3. 시나리오 **2종** 데이터 팩(AWR 발췌, ASH CSV, XPLAN, 시스템 맥락)과 재현/초기화 가이드
4. 진단퀴즈 10문항·Exit Ticket 5문항·채점 루브릭(100점: 구간 15, 증거 30, 원인 25, 조치/위험 20, 전달 10)
5. 강사 운영가이드(타임박스, 힌트 3단계, 예상 오진, 장애 대응)와 접근성·기술 QA 체크리스트

**인수 조건:** 모든 정답은 제공 데이터로 재현 가능해야 하며, 임계값만으로 단정하지 않고 기준선 비교를 포함한다. SQL/뷰는 Oracle 19c에서 검증하고, 실습 시작부터 제출까지 125분 내 완주율 80% 이상을 파일럿으로 확인한다.
