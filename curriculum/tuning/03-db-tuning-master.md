# DB 튜닝 마스터 (성능진단·튜닝)

- **트랙**: A · DB 튜닝
- **레벨**: L4
- **상태**: 기획 (체계화 예정) — 현재 구현된 실습은 [성능진단 소모임](../study-performance-club.md)으로 **별도 운영** 중
- **대상**: 성능 장애를 진단하고 튜닝하는 DBA / 기술서비스 엔지니어
- **선수과정**: [SQL 전문가](02-sql-advanced.md)
- **목표**: 아키텍처~대기이벤트~실행계획을 잇는 성능 진단 체계를 갖추고, 실전 장애를 진단·튜닝한다.

## 학습자료 (세션)
1. **아키텍처 개요** — 인스턴스/프로세스/메모리(SGA/PGA), 버퍼 캐시, 리두/언두 (`session_1_architecture_overview.md`)
2. **이력 분석** — 대기 이벤트, ASH/AWR로 과거 추적 (`session_2_history_analysis.md`)
3. **실행 계획** — 플랜 트리, 조인/인덱스, 카디널리티 (`session_3_execution_plan.md`)

## 실습 (인터랙티브 랩)
| 랩 | 내용 |
|---|---|
| 성능 대시보드 | 실시간 지표 변화 모니터링 |
| 실행 계획 시각화 | 플랜 트리/노드 해석 |
| 인덱스 시뮬레이터 | B-tree 탐색 시각화 |
| 락 & 동시성 샌드박스 | 블로킹/데드락 시뮬레이션 |
| 플랜 진단 (기초) | 오차율로 병목 노드 찾기 |
| 플랜 진단 (고급) | 3단계 정밀 진단 + 채점 |
| 적응형 최적화 (Adaptive) | 카디널리티 피드백/Adaptive Plan/SQL Plan Directive |
| 조인 비교 / 조인 문법 | 조인 알고리즘 비용 비교, 문법 실습 |
| ASH / AWR 분석 | 미시/거시 성능 분석 |
| SQL Trace / TKPROF | 호출 통계 3단계 진단 |
| 바인드 변수 & 파싱 | 리터럴 vs 바인드 시뮬레이터 |
