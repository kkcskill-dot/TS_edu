# SQL 전문가

- **트랙**: A · DB 튜닝
- **레벨**: L3
- **상태**: 기획
- **대상**: 실행계획을 읽을 수 있고, 복잡한 SQL을 정교하게 다루려는 실무자
- **선수과정**: [SQL 튜닝 기본](01-sql-tuning-basics.md)
- **목표**: 옵티마이저의 판단을 깊이 이해하고, 복잡한 쿼리 변환·힌트·통계를 통제한다.

## 세션 구성
| 세션 | 학습자료 | 실습 |
|---|---|---|
| 1. 쿼리 변환 | 뷰 머지, 서브쿼리 언네스팅, 조인 제거/순서 | 변환 진단 |
| 2. 카디널리티 & 통계 | 선택도 계산, 히스토그램, 결합 선택도(확장통계) | 카디널리티 진단 |
| 3. 적응형 최적화 | 카디널리티 피드백, Adaptive Plan, SQL Plan Directive | 적응형 최적화 랩 |
| 4. 힌트 & 플랜 제어 | 주요 힌트, SQL Plan Baseline, Profile | 힌트 실습 |
| 5. 분석함수·고급 SQL | 윈도우/모델절/정규식, Top-N 최적화 | 작성 챌린지 |
