# SQL 튜닝 기본

- **트랙**: A · DB 튜닝
- **레벨**: L2
- **상태**: 기획
- **대상**: SQL을 작성할 수 있고, 느린 쿼리를 스스로 개선하고 싶은 개발자/운영자
- **선수과정**: [SQL 기초](../foundation/sql-foundation.md)
- **목표**: 실행계획을 읽고, 인덱스/조인의 기본 원리로 느린 SQL을 개선한다.

## 세션 구성
| 세션 | 학습자료 | 실습 |
|---|---|---|
| 1. 옵티마이저 기초 | 비용 기반 최적화(CBO), 통계의 역할, 실행계획 읽는 법 | 실행계획 시각화 |
| 2. 인덱스 기본 | B-tree 구조, 인덱스 스캔 vs 풀스캔, 선택도 | 인덱스 시뮬레이터 |
| 3. 조인 기본 | NL/Hash/Sort Merge 개념과 선택 기준 | 조인 비교 실험실 |
| 4. 자주 만나는 안티패턴 | 묵시적 형변환, 함수 적용, OR/LIKE, 페이지네이션 | 진단 실습 |
| 5. 바인드 변수 | 하드/소프트 파싱, 커서 공유 | 바인드 파싱 시뮬레이터 |
