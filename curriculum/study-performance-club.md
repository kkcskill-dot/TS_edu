# 성능진단 소모임 (별도 운영 스터디)

- **분류**: 사내 스터디 (정규 교육과정과 **별개**)
- **상태**: **운영 중** ✅ (현재 사이트에 구현된 실습들)
- **성격**: 기술서비스팀에서 별도로 진행하는 성능진단·튜닝 스터디. 기초~심화가 혼재하며, 정규 2-트랙 로드맵의 단일 레벨에 매핑하지 않고 **하나의 묶음으로 유지**한다.
- **진입**: 홈의 "성능진단 소모임" 카드 → 학습자료/실습/퀴즈 메뉴.

## 학습자료 (세션)
1. 아키텍처 개요 — SGA/PGA, 버퍼 캐시, 리두/언두 (`session_1_architecture_overview.md`)
2. 이력 분석 — 대기 이벤트, ASH/AWR (`session_2_history_analysis.md`)
3. 실행 계획 — 플랜 트리, 조인/인덱스, 카디널리티 (`session_3_execution_plan.md`)

## 실습 (인터랙티브 랩)
성능 대시보드 · 실행계획 시각화 · 인덱스 시뮬레이터 · 락/동시성 샌드박스 · 플랜 진단(기초/고급) · 적응형 최적화 · 조인(비교/문법) · ASH · AWR · SQL Trace/TKPROF · 바인드 변수 & 파싱

## 퀴즈
SQL 튜닝(기초) · 성능진단 퀴즈 · 실행계획 퀴즈
